
As part of the [Monk_Mate Twitch stream](https://twitch.tv/monk_mate), viewers can redeem **DECTalk TTS** with Channel Points.

DECTalk is a classic 1980s text-to-speech voice system, best known online for its robotic voice effects and _Moonbase Alpha_-style singing. Normally, DECTalk uses confusing inline commands, so this stream has **Easy Mode tags** that make it much simpler to use.

Advanced DECTalk and _Moonbase Alpha_ formatting still works for anyone who already knows it.

---

## How to Use It

Redeem **DECTalk TTS** and type your message with any tags you want.

Tags usually work best at the start of your message.

```text
#betty #fast hello there
```

You can combine multiple tags:

```text
#harry #deep #slow I have made a terrible mistake
```

For advanced users, the [_Ultimate Moonbase Alpha Handbook_ by jk3](https://steamcommunity.com/sharedfiles/filedetails/?id=482628855) is a useful reference, especially the singing section.

```text
#frank

```

```text

```

## Sound Effects

Use these by themselves, or add a message after them:

```text
#siren
#alarm
#victory
#fail
#sad
#beep
#boop
```

Examples:

```text
#siren The ambulance is coming!
```

```text
#victory, mission complete
```

The bot will play the sound effect, pause briefly, reset the voice, then read the message.

---

## Pauses

Use a pause tag to add silence.

```text
hello #pause500 there
```

`#pause500` means a **500 millisecond pause**, which is half a second.

Useful pause examples:

```text
#pause250
#pause500
#pause1000
#pause1s
#pause2s
```

You can also use the short version:

```text
hello #p1s there
```

---

## Easy Singing

Use `#sing`, then a syllable, followed by pitch numbers.

```text
#sing dah 20 22 24
```

This sings “dah dah dah” with the pitch going upward.

Lower number = lower note.  
Higher number = higher note.

A good pitch range is:

```text
16 to 30
```

More examples:

```text
#sing dah 18 20 22 24
#singfast laa 18 20 22 24 26 28
#singlong aa 20 22 24
```

Useful singing sounds:

```text
dah
bah
aa
ae
iy
uw
oh
laa
```

## Advanced Users

Raw DECTalk and _Moonbase Alpha_ syntax still works.

Example:

```text
[dah<300,20>dah<300,22>dah<600,24>]
```

Most viewers should use Easy Mode tags first, but advanced users can still experiment with inline formatting.
